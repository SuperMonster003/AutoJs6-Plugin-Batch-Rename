Batch Rename プラグインは, PowerToys の [PowerRename](https://learn.microsoft.com/windows/powertoys/powerrename) を参考にした一括リネーム機能を AutoJs6 に追加します. 検索と置換, 正規表現, カウンター, 日付変数, ランダム文字列, 写真のメタデータ, 漢字のピンイン変換で多数のファイルとフォルダーの名前を一度に変更でき, 変更前にすべての結果をプレビューし, 変更後に元に戻せます.

### 機能ハイライト

- 検索と置換: プレーンテキストまたは JavaScript の正規表現, すべて一致または最初の一致のみ, 大文字と小文字の区別の有無, 名前, 拡張子またはその両方に適用.
- 変数: カウンター (`${start=1;increment=1;padding=3}`), 更新日時または現在時刻の日付変数 (`$YYYY`, `$MM`, `$DD` など) とランダム文字列. 書き方は PowerRename と同じです.
- ピンイン変換: "名前の整理" の "漢字をピンインに変換" で新しい名前の漢字をピンインにし, 置換変数 `${pinyin}` で元の名前のピンインを挿入します. 声調, 音節の区切り, 大文字小文字, 頭文字のみを選べ, 多音字は語句から判断します.
- 写真のメタデータ: "対象と書式" の "メタデータ変数" をオンにすると, 撮影日時, カメラ, レンズ, 絞り, シャッター速度, ISO 感度, GPS など 25 項目で写真に名前を付けられます (`$DATE_TAKEN_YYYY`, `$CAMERA_MODEL` など). メタデータのない行には印が付きます.
- 名前付きプリセット: 上部バーの "プリセット" ボタンで現在のオプションをプリセットとして保存し, タップ 1 回で読み込めます. 名前の変更, 削除, ファイルやクリップボードでのインポートとエクスポートができ, スクリプトからも使えます.
- 名前の整理: 大文字と小文字の変換, Unicode 正規化, 全角から半角への変換, 使用できない文字の置き換え, 前後の空白の削除, 既存の名前の番号の続き.
- 実行前のプレビュー: 元の名前と新しい名前を項目ごとに表示し, チェックを外して除外したり, 変更される項目だけを表示したりできます. 新しい名前が使用中のときは, 変更しない, スキップ, 番号を付ける, 既存の項目を置き換える, から選べます.
- 元に戻す: AutoJs6 はスクリプトとプラグインごとに最近 20 回分 (50 または 100 に変更可) の名前変更を保存し, ファイルマネージャーからもスクリプトからも元に戻せます. AutoJs6 の "名前の変更履歴" ページで確認, 元に戻す, 削除することもできます. 元に戻す前にファイルが再び変更されていないか確認します.
- 画面は AutoJs6 のテーマカラー, ダークモード, 言語に従い, 前回のオプションと最近使った検索/置換テキストを記憶できます.

### ファイルマネージャーでの使い方

プラグインをインストールして有効にすると, AutoJs6 のファイルマネージャーに 3 つの入口が加わります:

- 複数選択: ファイルやフォルダーを選択し, 選択バーの "一括で名前変更" をタップします (プラグインの操作が複数あるときは "詳細" の中にあります).
- フォルダーメニュー: フォルダーのメニューで "中の項目を一括で名前変更" を選ぶと, そのフォルダー内の項目の名前を変更します.
- 名前変更ダイアログ: ファイルやフォルダーを 1 つ名前変更するとき, ダイアログ右上の "詳細" メニューから "一括で名前変更..." を選びます. 同じメニューの最後にある "名前の変更履歴" で過去の一括変更を確認して元に戻せます.
- プラグインの画面で検索と置換の内容を入力するとプレビューがすぐに更新されます. チェックを外して除外し, "名前を変更" で実行します. その後 "前回の一括変更を元に戻す" で元の名前に戻せます. 上部バーの "その他のオプション" メニューの最後にある "名前の変更履歴" で AutoJs6 の名前の変更履歴ページを開きます.

スクリプト API は [AutoJs6 ドキュメント](https://docs.autojs6.com/#/files?id=m-batchrename), 開発の記録は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Batch-Rename) を参照してください.
