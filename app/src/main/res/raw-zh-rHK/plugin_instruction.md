Batch Rename 插件為 AutoJs6 提供批量重新命名能力, 功能參照 PowerToys 的 [PowerRename](https://learn.microsoft.com/windows/powertoys/powerrename): 以尋找取代, 正則表達式, 計數器, 日期與隨機變數, 相片元數據及漢字轉拼音一次重新命名多個檔案和資料夾, 執行前可完整預覽, 執行後可以撤銷.

### 功能亮點

- 尋找與取代: 支援純文字或 JavaScript 正規表達式, 可選全部配對或只取代第一處, 區分或忽略大小寫, 只作用於名稱, 副檔名或兩者.
- 變數: 計數器 (`${start=1;increment=1;padding=3}`), 取檔案修改時間或目前時間的日期變數 (`$YYYY`, `$MM`, `$DD` 等) 與隨機字串, 寫法與 PowerRename 一致.
- 漢字轉拼音: "名稱清理" 中的 "漢字轉拼音" 把新名稱中的漢字轉為拼音, 取代變數 `${pinyin}` 插入原名的拼音; 可選聲調, 音節分隔, 大小寫與只取首字母, 多音字按詞組判斷.
- 相片元數據: 開啟 "範圍與格式" 中的 "元數據變數" 後, 可用拍攝時間, 相機, 鏡頭, 光圈, 快門, 感光度, GPS 等 25 項資訊命名相片 (`$DATE_TAKEN_YYYY`, `$CAMERA_MODEL` 等), 缺少元數據的列會標出.
- 命名預設: 用頂欄的 "預設" 按鈕把目前選項儲存為預設並一點載入, 可重新命名, 刪除, 經檔案或剪貼簿匯入匯出, 腳本中也能引用.
- 名稱整理: 大小寫轉換, Unicode 正規化, 全形轉半形, 取代不允許的字元, 去除首尾空格, 以及接續既有名稱的編號.
- 先預覽再執行: 逐項顯示原名與新名, 可取消勾選排除項目, 可只顯示改名項目; 新名稱被佔用時可選擇不重新命名, 略過, 加上編號或取代既有項目.
- 可以復原: AutoJs6 為腳本與每個插件各保存最近 20 個重新命名批次 (可改為 50 或 100), 檔案管理器與腳本中都能復原, 也可在 AutoJs6 的 "重命名歷史" 頁面中查看, 復原或刪除; 復原前會檢查檔案是否已再次修改.
- 介面跟隨 AutoJs6 的主題色, 夜間模式與語言, 可記住上次選項與最近使用的尋找和取代文字.

### 在檔案管理器中使用

安裝並啟用插件後, AutoJs6 檔案管理器中有三處入口:

- 多選: 選取若干檔案或資料夾, 在選取列中點 "批次重新命名" (有多個插件動作時位於 "更多" 中).
- 資料夾選單: 在資料夾的選單中選擇 "批次重新命名其中的項目", 為該資料夾中的項目改名.
- 重新命名對話框: 重新命名單一檔案或資料夾時, 點對話框右上角的 "更多" 選單, 選擇 "批次重新命名...". 同一選單末尾的 "重命名歷史" 可查看與復原以往的批次.
- 在插件介面中輸入尋找與取代內容, 預覽會即時更新; 取消勾選可排除項目, 點 "重新命名" 執行, 之後可以點 "復原上一批" 恢復原名. 頂欄 "更多選項" 選單末尾的 "重命名歷史" 會開啟 AutoJs6 的重命名歷史頁面.

腳本 API 見 [AutoJs6 文件](https://docs.autojs6.com/#/files?id=m-batchrename), 開發記錄見 [項目主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-Batch-Rename).
